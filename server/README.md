# Travel Engine 🚀✨

Honestly, this is the backend engine that keeps the whole travel platform from falling apart. It's built with Rust because we ain't gonna deal with memory leaks and random crashes in production. 

If you're trying to figure out how this works, lemme give you the quick rundown. It handles all the listings, bookings, payments, and transport logic without breaking a sweat. It's actually cooking.

## Getting Started

First, make sure you copy the env example so things don't blow up:
```bash
cp .env.example .env
```

Then compile and run it:
```bash
cargo run
```

If the database isn't initialized, run the migrations:
```bash
# you gotta run these migrations before doing anything else
# check the migrations folder if you want to see the schemas
```
